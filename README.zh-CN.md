# 凡影成艺 · Photo Alchemy

[English](./README.md)

照片记录我们曾经看见的事物，也常常藏着尚未被真正看见的动作、间隔、色彩记忆与结构张力。

Photo Alchemy 希望从这些潜在关系出发，让普通的照片不再普通。它不依靠滤镜为照片套上一层风格，而是重新发现画面内部已有的力量，让熟悉的瞬间以新的方式被观看，并成为具有独立表达的作品。

它是一套尊重原始照片、同时鼓励艺术再创作的 Agent Skill，不是固定风格预设，也不是对原图的机械描摹。

## 一张照片，三种重新观看的方式

- `abstraction`（抽象）：当具体形象逐渐松开，画面中的力量、节奏、间隔与色彩会留下什么？
- `extend`（扩展）：当照片不再止于原有边界，它还可以向哪里生长？
- `reduction`（减法）：当偶然和冗余的信息退去，什么才是这个瞬间真正不能失去的部分？

## 方法概览

| 方法 | 成品是否保留照片像素 | 主要目标 |
| --- | --- | --- |
| `abstraction`（抽象） | 否 | 将画面的核心感知事件转译为一张完整的抽象作品。 |
| `extend`（扩展） | 是 | 保留足以说明场景的真实摄影区域，并以独立材料语言向外扩展。 |
| `reduction`（减法） | 否 | 通过有选择的语义与视觉减法重新绘制场景，同时保留表现性结构。 |

`reduction` 只是方法名称，不表示降低分辨率，也不表示把所有视觉层次压缩到最低。

## 设计原则

- 先保留关系，再处理表面细节。
- 构图、色彩、节奏和辅助元素必须来自原始照片中的真实依据。
- 三种方法各自保持独立的画面逻辑与材料语言。
- 不套用固定版式，不复刻他人的标志性视觉语言，不硬编码标题，不添加无功能装饰，也不新增或伪造 Logo、水印、署名、元数据或推广文字；`extend` 的真实摄影锚点中原本存在的标识仍属于源图像素。
- 成图需要在正常尺寸与缩略图尺寸下检查；只有出现明确问题时，才进行至多一次定向修正。

## 安装

### Codex

将完整的 `photo-alchemy` 文件夹复制到 Codex Skills 目录：

```text
~/.codex/skills/photo-alchemy/
```

Windows 通常对应：

```text
%USERPROFILE%\.codex\skills\photo-alchemy\
```

安装后新建任务，让 Codex 重新发现该 Skill。

### 其他 Agent 平台

核心流程采用可移植的 `SKILL.md` 与相对路径 `references/`。兼容 Agent Skills 的平台可以按照自身规则导入整个文件夹或 ZIP 包，但宿主平台至少需要提供：

- 图片输入与视觉分析能力；
- 支持参考图的位图生成或编辑能力；
- 读取 Skill 内参考文件的权限；
- 保存并返回生成图片的能力。

`agents/openai.yaml` 是 OpenAI 平台的界面元数据，其他平台可以忽略。

## 使用方式

提供一张原始照片，然后选择一种方法：

```text
$photo-alchemy method=abstraction
$photo-alchemy method=extend
$photo-alchemy method=reduction
```

也可以直接使用自然语言：

```text
使用 $photo-alchemy 将这张照片处理为抽象作品。
使用 $photo-alchemy 扩展这张照片，形成原创材料构图。
使用 $photo-alchemy 对这张照片做减法处理，同时保留动作与氛围。
```

在开发测试或横向比较时，可以明确要求全部方法：

```text
$photo-alchemy method=all
```

如果没有指定方法，Skill 可以根据照片选择更合适的方向。

## 工作流程与输出

Skill 会：

1. 判断不可丢失的源关系、关键视觉事实、视觉重量、安静区域、源锚点、色彩机会与应当删除的描述性细节；
2. 为 `abstraction`、`extend` 或 `reduction` 填写紧凑的方法简报；
3. 将简报编译为包含命题、方法构造、色彩与再现边界的三段式图像提示词；
4. 根据原图方向与构图选择输出比例，而不是强制使用固定海报尺寸；
5. 始终从原始照片生成，不以其他方法的结果作为中间参考；
6. 检查语义完整性、构图、方法区分度及可见缺陷；
7. 返回完成的位图作品与简短的方法说明。

每种已选方法默认返回一张完成的位图，并标明方法名称；同时使用用户所用语言给出一至两句创作说明。场景卡、方法简报和完整生成提示词默认保持内部，不主动公开。除非用户明确要求，否则 Skill 不添加可见标题、排版文字、署名、来源信息、元数据或推广内容。

目标不是把每张照片都变得宏大，而是找到那个曾被忽略、却足以让这张照片成为它自己的关系。

## 原图处理

原始照片仅用于用户当前请求的生成任务。除非用户明确要求，Skill 不会主动搜索、公开、写入项目仓库或在其他任务中复用该照片。宿主平台仍可能把图片发送给其配置的图像生成服务，因此相应服务的隐私与数据条款同样适用。
